# How to Peel a Green Plantain

An interactive English tutorial built with HTML, CSS, and vanilla JavaScript.

## Run it with Visual Studio Code
1. Extract `plantain-tutorial.zip`.
2. Open the `plantain-tutorial` folder in Visual Studio Code.
3. Install the **Live Server** extension if it is not installed.
4. Right-click `index.html` and choose **Open with Live Server**, or select **Go Live**.
5. The tutorial will open in your browser. Save your changes with `Ctrl + S` to refresh the page.

The images are included in the `images` folder, so the tutorial does not depend on external image links. Google Fonts is optional; if it is unavailable, a fallback font is used.
